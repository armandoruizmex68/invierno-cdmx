# Invierno CDMX poniente

Microclima y pronóstico del invierno 2026-27 por zona para el poniente y norponiente de la Ciudad de México (Naucalpan, Tlalnepantla, Atizapán de Zaragoza y alrededores).

- App móvil (instalable como PWA): raíz de este sitio.
- Versión de escritorio: `/escritorio/`.

Las cifras son un modelo estadístico, no un pronóstico oficial; los parámetros por zona no están calibrados con estaciones locales. Para alertas, consulta al SMN y a Protección Civil.
