# Invierno CDMX

Microclima y pronóstico del invierno 2026-27 por zona para el poniente y norponiente de la Ciudad de México (Tlalnepantla, Naucalpan, Atizapán de Zaragoza, Santa Fe, Indios Verdes y más).

- App móvil (instalable como PWA): raíz de este sitio.
- Versión de escritorio: `/escritorio/`.

Generado desde el proyecto Invierno CDMX. Las cifras son un modelo estadístico, no un pronóstico oficial: para alertas, consulta al SMN y a Protección Civil de la CDMX y del Estado de México.

Tipografías incrustadas: Source Sans 3 y Barlow Condensed, licencia SIL Open Font License 1.1 (https://openfontlicense.org).
